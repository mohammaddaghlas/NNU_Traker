# 🎓 بوت جامعة النجاح للإشعارات - الإصدار المطور

بوت تليجرام متطور لطلاب جامعة النجاح يراقب أخبار الجامعة من مصادر متعددة ويرسل إشعارات فورية عند وجود عطلة أو تعليق دوام.

## ✨ الميزات الجديدة

### 📰 مصادر الأخبار
- **موقع الجامعة الرسمي**: www.najah.edu
- **صفحة فيسبوك**: www.facebook.com/ANajahUni

### 🔔 نظام الإشعارات
- مراقبة تلقائية كل 5 دقائق
- كشف ذكي لإعلانات العطلات وتعليق الدوام
- منع تكرار الإعلانات
- مصدر كل إعلان (موقع أو فيسبوك)

### ⚙️ الاشتراك الاختياري في فيسبوك
- ميزة اختيارية يمكن للمستخدم تفعيلها/تعطيلها
- أزرار تفاعلية للتحكم في الإعدادات
- إحصائيات عن المشتركين في كل خدمة

### 🎯 الأوامر المتاحة
- `/start` - البدء وتسجيل المشترك
- `/help` - عرض المساعدة
- `/status` - عرض حالة الاشتراك
- `/unsubscribe` - إلغاء الاشتراك

### 🔘 الأزرار التفاعلية
- 🔔 تفعيل/تعطيل إشعارات فيسبوك
- 📊 عرض الحالة والإحصائيات

## 🚀 التثبيت والتشغيل

### ⚠️ هام جداً قبل البدء: الحصول على توكن جديد
التوكن القديم تم كشفه في الكود، **يجب إلغاؤه فوراً** لحماية البوت!

1. افتح @BotFather على تيليجرام
2. أرسل الأمر: `/revoke`
3. اختر البوت الخاص بك
4. انسخ التوكن الجديد

---

### الطريقة 1: النشر على Render للعمل 24/7 (موصى به)

لجعل البوت يعمل بشكل دائم بدون توقف:

#### الخطوة 1: اربط حسابك بـ Render
1. سجل الدخول إلى https://render.com
2. اضغط على **New +** → **Blueprint**
3. الصق رابط الريبوزتوري: `https://github.com/mohammaddaghlas/NNU_Traker`
4. اضغط **Connect**

#### الخطوة 2: أضف متغير البيئة
1. في صفحة الخدمة على Render، اذهب إلى **Environment**
2. اضغط **Add Environment Variable**
3. أضف المتغير التالي:
   - **Key:** `TELEGRAM_BOT_TOKEN`
   - **Value:** (التوكن الجديد من BotFather)
4. اضغط **Save**

#### الخطوة 3: انتظر التشغيل
- سيقوم Render تلقائياً ببناء وتشغيل البوت
- سيبدأ البوت بالعمل خلال 2-5 دقائق
- البوت سيعمل 24/7 بدون توقف!

---

### الطريقة 2: التشغيل المحلي (للتجربة فقط)

```bash
# استنساخ المشروع
git clone https://github.com/mohammaddaghlas/NNU_Traker.git
cd NNU_Traker

# تثبيت المكتبات
pip install -r requirements.txt

# إنشاء ملف .env وإضافة التوكن
cp .env.example .env
# عدل ملف .env وأضف التوكن الجديد مكان your_new_token_here

# تشغيل البوت
python bot.py
```

⚠️ **ملاحظة**: التشغيل المحلي سيتوقف عند إغلاق الجهاز. للاستخدام الدائم، استخدم Render.

## 📊 قاعدة البيانات

يستخدم البوت SQLite مع الجداول التالية:

### جدول المشتركين (subscribers)
- chat_id: معرف المستخدم
- username: اسم المستخدم
- first_name, last_name: الاسم
- subscribed_at: تاريخ الاشتراك
- is_active: حالة الاشتراك
- **facebook_subscription**: اشتراك فيسبوك (جديد!)

### جدول الإعلانات المرسلة (sent_announcements)
- title: عنوان الإعلان
- content: المحتوى
- url: الرابط
- sent_at: تاريخ الإرسال
